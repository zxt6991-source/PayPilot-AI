# 三分钟演示脚本

| 时间 | 屏幕操作 | 讲解 |
|---|---|---|
| 0:00–0:30 | 打开「支付总览」，选择德国、Klarna、最近 24 小时、全部终端。 | 数据来自固定种子和回放快照。当前 1,784 / 2,000，基准 3,800 / 4,000，成功率下降 5.8 个百分点。 |
| 0:30–1:00 | 点击「开始 AI 诊断」，查看任务时间线，再打开报告。 | 服务端读取与看板相同的指标。每次下钻都保存查询参数和结果。 |
| 1:00–1:35 | 展开 get_error_distribution 和 KB-002。 | Android 的 150 笔失败中，有 90 笔命中模拟回跳超时。建议优先核查客户端回跳和渠道终态。 |
| 1:35–2:05 | 选择「继续追问」，输入「是否与 Android 版本发布有关」。 | 新 run 关联原任务，加入模拟发布事件。报告保留因果关系的不确定性。 |
| 2:05–2:30 | 提交反馈，导出 Markdown，重新打开原报告。 | 反馈落到对应 run/report，报告可以独立复核。 |
| 2:30–3:00 | 打开评测中心，查看开发集、留出集及模型标识。 | 逐例结果有 Trace 和数据库核算。真实业务效果及人工耗时改善仍待研究。 |

# DEMO 支付口径 v1

每条 payment_attempt_id 是一次尝试，重复订单的重试分别计数。SUCCESS / FAILED 按 finalized_at 归入左闭右开 UTC 窗口；仅纳入已成熟的终态。PSR 是成功数除以有效尝试数。空分母返回 null。百分点差等于两个原始比例之差乘 100。PENDING 和 CANCELLED 按创建时间另列，只有截止快照仍处于对应状态的记录才计入。

固定快照为 2026-11-16 10:00 UTC，默认成熟延迟 5 分钟。当前窗口截至成熟截止点，以所选周期为宽度。演示基准由紧邻当前期之前、等宽且无重叠的两个窗口合并，按尝试数加权。界面只比较两者的成功率。每组有效尝试少于 30 标记 LOW_SAMPLE。
